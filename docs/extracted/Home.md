# Home

PSAistudio Payment Website (SaaS)

Short description

A lightweight, extensible payment website SaaS built to accept payments, manage subscriptions, and provide developer-friendly integration hooks for merchants and partners.

Key features
- Multiple payment gateway support (Stripe, PayPal, and pluggable adapters)
- Subscription & one-time payment billing
- Customer portal & invoice history
- Webhook handling and retry logic
- Multi-tenant-ready structure with environment-based configuration
- Dockerized for easy deployment; CI-ready for automated testing
