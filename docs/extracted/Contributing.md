# Contributing

How to contribute:
- Fork the repo and create a branch for your feature/fix
- Run tests and linters locally
- Open a pull request with a descriptive title and summary

Pull request process
- Target branch: main (or the repository's default)
- Include screenshots or logs if relevant
- CI will run unit, integration, and lint checks

Code style
- Follow ESLint + Prettier configuration in the repo
- Keep commits small and focused

Maintainers will review and provide feedback; thank you for contributing!
